Mods for DCS World. Each one is a free zip.

    Install a mod in three steps

    1. Download the zip

      Each mod is one zip file. Its own page has the install steps and what changed in each release.

    2. Copy it into Saved Games

      Unzip it and copy the folder into Saved Games\DCS\Mods\aircraft. DCS reads it from there, so updates and repairs leave it alone.

    3. Pick it in DCS

      Start DCS and choose the aircraft in the mission editor. Delete the folder to remove it.

    Every mod is free to download

    No account and no sign-up. Back up Saved Games\DCS before you add one.
